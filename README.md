# Dell-Drive-Firmware
Central Store for Dell Server Drive Firmware

This is a consolidated source of all published Dell Drive Firmware available on the Dell Website.

These are JUST the firmware files themselves to be used with the offline Dell Nautilus Drive Firmware update utility.

To use, just download the latest utility (https://www.dell.com/support/home/en-vg/drivers/driversdetails?driverid=9rp29) and follow the directions in the Dell Video (https://www.dell.com/support/contents/en-vg/videos/videoplayer/How-to-Import-Drive-Firmware-via-Dell-Nautilus-Firmware-Update-Utility/6310278702112) or the tech support article (https://www.dell.com/support/kbdoc/en-vg/000197914/import-drive-firmware-into-nautilus-utility) to include the drive firmware.
